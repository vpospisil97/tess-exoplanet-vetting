# Experiment E1 - Feature-level ablation

## Research question

How much does the TESS classifier benefit from combining local and global phase-folded light-curve views?

## Hypothesis

Using both views provides higher validation Average Precision than using either view alone.

## Experimental design

- Same dataset and TIC-based split.
- Same input preprocessing.
- Same two-branch CNN definition.
- Same training hyperparameters.
- Three seeds: 42, 123, 2026.
- Learning rate: 0.001.
- Batch size: 32.
- Dropout: 0.3.
- Weight decay: 0.0001.
- Maximum epochs: 35.
- Early stopping patience: 7.
- Checkpoint selection: validation AP.
- Test set not evaluated.

## Ablation method

Each input view is encoded by its own convolutional encoder.

- Both: retain both encoder outputs.
- Local only: replace global encoder features with zeros.
- Global only: replace local encoder features with zeros.

The feature masking is applied in both training and validation.

This prevents inactive encoders from contributing constant features generated by convolution biases or BatchNorm.

Although the declared model has the same number of parameters, inactive branches receive no supervised gradient and are not functionally used.

## Limitations

- This is a feature-ablation study.
- Disabled branches do not contribute features or useful trainable capacity.
- The compared variants therefore have different effective model capacities.
- Fixed-threshold F1 can be affected by probability calibration.
- AP and ROC-AUC measure ranking without choosing a threshold.
- Hyperparameters were already selected on the same validation split.
- Results are not independent test-set estimates.
- Processing artifacts and dataset biases remain possible.
